public class EchoRequest {

import org.springframework.web.bind.annotation.PostMapping;

## Exercise 3: Using @PathVariable

Question: Write a Spring Boot REST controller with a GET endpoint "/square/{number}" that takes a path variable "number" and returns the square of that number as a string.

Answer:

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MathController {

    @GetMapping("/square/{number}")
    public String square(@PathVariable int number) {
        int square = number * number;
        return String.valueOf(square);
    }
}
```

import org.springframework.web.bind.annotation.CookieValue;

import org.springframework.web.bind.annotation.RestController;

## Exercise 7: Using @RequestPart

Question: Write a Spring Boot REST controller with a POST endpoint "/upload" that accepts a multipart request with a part named "file" which is a file, and a part named "description" which is a string. The method should return the size of the file and the description.

Answer:

First, make sure you have the necessary dependencies for handling multipart requests. Then:

```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;

@RestController
public class UploadController {

    @PostMapping("/upload")
    public String upload(@RequestPart("file") MultipartFile file, @RequestPart("description") String description) {
        long size = file.getSize();
        return "File size: " + size + ", Description: " + description;
    }
}
```

### 3. 在 Python 中使用 `codecs` 模块

如果你在使用 Python 进行文件处理，可以使用 `codecs` 模块来读取和写入不同编码的文件：

```python
import codecs

# 读取 UTF-8 编码的文件
with codecs.open('input.txt', 'r', 'utf-8') as f:
    content = f.read()

# 写入 GBK 编码的文件
with codecs.open('output.txt', 'w', 'gbk') as f:
    f.write(content)
```

### 4. 在 JavaScript 中使用 `iconv-lite` 库

如果你在 Node.js 环境中，可以使用 `iconv-lite` 库来处理编码转换：

```javascript
const fs = require('fs');
const iconv = require('iconv-lite');

// 读取 UTF-8 编码的文件
const content = fs.readFileSync('input.txt', 'utf8');

// 将内容转换为 GBK 编码
const gbkContent = iconv.encode(content, 'gbk');

// 写入 GBK 编码的文件
fs.writeFileSync('output.txt', gbkContent);
```

### 5. 在 Java 中使用 `Charset` 类

```java
import java.nio.charset.Charset;
import java.nio.file.Files;
import java.nio.file.Paths;
import java.nio.file.StandardOpenOption;
import java.util.List;

public class EncodingConverter {
    public static void main(String[] args) throws Exception {
        // 读取 UTF-8 编码的文件
        List<String> lines = Files.readAllLines(Paths.get("input.txt"), Charset.forName("UTF-8"));

        // 写入 GBK 编码的文件
        Files.write(Paths.get("output.txt"), lines, Charset.forName("GBK"), StandardOpenOption.CREATE);
    }
}
```

**Question 8**  
**Prompt**: Explain how a bill becomes a law in the United States.  
**Answer**:  
1. **Drafting**: A member of Congress writes a bill.  
2. **Introduction**: The bill is introduced in either the House or the Senate.  
3. **Committee Review**: The bill goes to a committee that studies it and may hold hearings.  
4. **Markup**: The committee can change the bill and then votes to send it to the full chamber.  
5. **Debate**: The full House or Senate debates the bill and may propose amendments.  
6. **Vote**: The chamber votes on the bill. If it passes, it goes to the other chamber, where the process repeats.  
7. **Conference Committee**: If the two chambers pass different versions, a conference committee reconciles them.  
8. **Final Vote**: Both chambers vote on the final version.  
9. **Presidential Action**: The President signs the bill into law or vetoes it.
