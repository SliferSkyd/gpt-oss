## Exercise 3: Using @PathVariable

Question: Write a Spring Boot REST controller with a GET endpoint "/square/{number}" that takes a path variable "number" and returns the square of that number as a string.

Answer:

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MathController {
    
    @GetMapping("/square/{number}")
    public String square(@PathVariable int number) {
        int square = number * number;
        return String.valueOf(square);
    }
}
```

## Exercise 7: Using @RequestPart

Question: Write a Spring Boot REST controller with a POST endpoint "/upload" that accepts a multipart request with a part named "file" which is a file, and a part named "description" which is a string. The method should return a string that says "Received file with description: {description}".

Answer:

```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;

@RestController
public class UploadController {
    
    @PostMapping("/upload")
    public String upload(@RequestPart("file") MultipartFile file, @RequestPart("description") String description) {
        return "Received file with description: " + description;
    }
}
```
