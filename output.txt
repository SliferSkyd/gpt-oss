## Exercise 7: Using @RequestPart

Question: Write a Spring Boot REST controller with a POST endpoint "/upload" that accepts a multipart request with a part named "file" which is a file, and a part named "description" which is a string. The method should return a string that says "Uploaded {description} with size {size} bytes".

Answer:

```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;

@RestController
public class UploadController {
    
    @PostMapping("/upload")
    public String upload(@RequestPart("file") MultipartFile file, @RequestPart("description") String description) {
        long size = file.getSize();
        return "Uploaded " + description + " with size " + size + " bytes";
    }
}
```

### 3. 在 Python 中使用 `codecs` 模块

如果你在使用 Python 进行文件处理，可以使用 `codecs` 模块来读取和写入不同编码的文件：

```python
import codecs

# 读取 UTF-8 编码的文件
with codecs.open('input.txt', 'r', 'utf-8') as f:
    content = f.read()

# 写入 GBK 编码的文件
with codecs.open('output.txt', 'w', 'gbk') as f:
    f.write(content)
```

### 4. 在 JavaScript 中使用 `iconv-lite` 库

```javascript
const fs = require('fs');

const gbkContent = iconv.encode(content, 'gbk');
```

```java
import java.nio.charset.Charset;

    }
}
```

**Question 4**  
**Prompt**: Explain the process of photosynthesis in simple terms.  
**Answer**:  
Photosynthesis is how plants make food.  
- Plants take in sunlight, water from the soil, and carbon dioxide from the air.  
- Inside the plant’s leaves, a green pigment called chlorophyll captures the sunlight.  
- The plant uses the sunlight’s energy to mix the water and carbon dioxide into glucose (a type of sugar) and oxygen.  
- The glucose is the plant’s food, and the oxygen is released into the air for us to breathe.

**Answer**:

2. Fold it in half lengthwise, then unfold.  
3. Fold the top corners to the center line.  
4. Fold the resulting triangle’s top point down to the bottom edge.  
5. Fold the airplane in half toward you.  
6. Fold the wings down so they meet the body.  
7. Adjust the wings for balance.
