## Exercise 3: Using @PathVariable

Question: Write a Spring Boot REST controller with a GET endpoint "/square/{number}" that takes a path variable "number" and returns the square of that number as a string.

Answer:

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MathController {
    
    @GetMapping("/square/{number}")
    public String square(@PathVariable int number) {
        int square = number * number;
        return String.valueOf(square);
    }
}
```

## Exercise 7: Using @RequestPart

Question: Write a Spring Boot REST controller with a POST endpoint "/upload" that accepts a multipart request with a part named "file" which is a byte array. The endpoint should return the size of the file in bytes.

Answer:

```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class UploadController {
    
    @PostMapping("/upload")
    public String upload(@RequestPart("file") byte[] file) {
        return "File size: " + file.length + " bytes";
    }
}
```

### 6. 在Java中使用 `InputStreamReader` 和 `OutputStreamWriter`

如果你在Java中处理文件，可以使用 `InputStreamReader` 和 `OutputStreamWriter` 来指定编码：

```java
import java.io.*;

public class ConvertEncoding {
    public static void main(String[] args) throws IOException {
        // 读取GBK编码的文件
        BufferedReader reader = new BufferedReader(new InputStreamReader(new FileInputStream("input.txt"), "GBK"));
        // 写入UTF-8编码的文件
        BufferedWriter writer = new BufferedWriter(new OutputStreamWriter(new FileOutputStream("output.txt"), "UTF-8"));

        String line;
        while ((line = reader.readLine()) != null) {
            writer.write(line);
            writer.newLine();
        }

        reader.close();
        writer.close();
    }
}
```

- Plants take in sunlight, water from the soil, and carbon dioxide from the air.  
- Inside the plant’s leaves, a green pigment called chlorophyll captures the sunlight.  
- The plant uses the sunlight’s energy to mix the water and carbon dioxide into glucose (a type of sugar) and oxygen.  
- The glucose is used as food for the plant, and the oxygen is released into the air for us to breathe.
