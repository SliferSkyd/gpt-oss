Question: Write a Spring Boot REST controller with a POST endpoint "/echo" that takes a JSON object with a single field "message" and returns the same object. Use a DTO class called EchoRequest with a field "message".

Answer:

First, let's define the DTO class:

```java
public class EchoRequest {
    private String message;

    // getters and setters
    public String getMessage() { return message; }
    public void setMessage(String message) { this.message = message; }
}
```

Now the controller:

```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class EchoController {
    
    @PostMapping("/echo")
    public EchoRequest echo(@RequestBody EchoRequest request) {
        return request;
    }
}
```

## Exercise 3: Using @PathVariable

Question: Write a Spring Boot REST controller with a GET endpoint "/square/{number}" that takes a path variable "number" and returns the square of that number as a string.

Answer:

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MathController {
    
    @GetMapping("/square/{number}")
    public String square(@PathVariable int number) {
        int square = number * number;
        return String.valueOf(square);
    }
}
```

## Exercise 6: Using @CookieValue

Question: Write a Spring Boot REST controller with a GET endpoint "/session-id" that reads a cookie named "SESSIONID" and returns its value. If the cookie is not present, return "No session ID".

Answer:

```java
import org.springframework.web.bind.annotation.CookieValue;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class SessionController {
    
    @GetMapping("/session-id")
    public String getSessionId(@CookieValue(value = "SESSIONID", defaultValue = "No session ID") String sessionId) {
        return sessionId;
    }
}
```

## Exercise 7: Using @RequestPart

Question: Write a Spring Boot REST controller with a POST endpoint "/upload" that accepts a multipart request with a part named "file" which is a file, and a part named "description" which is a string. The method should return a string that says "Received file with description: {description}".

Answer:

```java
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;

@RestController
public class UploadController {
    
    @PostMapping("/upload")
    public String upload(@RequestPart("file") MultipartFile file, @RequestPart("description") String description) {
        return "Received file with description: " + description;
    }
}
```

```bash
iconv -f gbk -t utf-8 input.txt > output.txt
```

### 3. 使用文本编辑器

许多现代文本编辑器（如 VS Code, Sublime Text, Notepad++ 等）都支持在打开文件时指定编码，或者在保存文件时选择不同的编码格式。你可以在编辑器中打开文件，检查并更改编码设置。

### 4. 使用在线工具

如果你不想安装任何软件，可以使用在线工具来转换文件编码。搜索“在线文件编码转换器”，你会找到许多可用的工具。

### 5. 在Python中使用 `pandas`

如果你正在处理数据文件（如CSV），可以使用 `pandas` 库来读取并转换编码：

```python
import pandas as pd

# 读取文件，指定原始编码
df = pd.read_csv('input.csv', encoding='gbk')

# 将DataFrame写入新文件，使用UTF-8编码
df.to_csv('output.csv', encoding='utf-8', index=False)
```

### 6. 在Java中使用 `InputStreamReader` 和 `OutputStreamWriter`

如果你在Java中处理文件，可以使用 `InputStreamReader` 和 `OutputStreamWriter` 来指定编码：

```java
import java.io.*;

public class ConvertEncoding {
    public static void main(String[] args) throws IOException {
        // 读取GBK编码的文件
        BufferedReader reader = new BufferedReader(new InputStreamReader(new FileInputStream("input.txt"), "GBK"));
        // 写入UTF-8编码的文件
        BufferedWriter writer = new BufferedWriter(new OutputStreamWriter(new FileOutputStream("output.txt"), "UTF-8"));

        String line;
        while ((line = reader.readLine()) != null) {
            writer.write(line);
            writer.newLine();
        }

        reader.close();
        writer.close();
    }
}
```

### 7. 在C#中使用 `StreamReader` 和 `StreamWriter`

如果你在C#中处理文件，可以使用 `StreamReader` 和 `StreamWriter` 来指定编码：

```csharp
using System;
using System.IO;
using System.Text;

class Program
{
    static void Main()
    {
        // 读取GBK编码的文件
        using (StreamReader reader = new StreamReader("input.txt", Encoding.GetEncoding("GBK")))
        {
            // 写入UTF-8编码的文件
            using (StreamWriter writer = new StreamWriter("output.txt", false, Encoding.UTF8))
            {
                string line;
                while ((line = reader.ReadLine()) != null)
                {
                    writer.WriteLine(line);
                }
            }
        }
    }
}
```

### 8. 在Node.js中使用 `iconv-lite`

如果你在Node.js中处理文件，可以使用 `iconv-lite` 包来转换编码：

```javascript
const fs = require('fs');
const iconv = require('iconv-lite');

// 读取GBK编码的文件

const decoded = iconv.decode(input, 'gbk');

// 写入UTF-8编码的文件
fs.writeFileSync('output.txt', decoded, 'utf8');
```

```powershell
Set-Content -Path "output.txt" -Value $content -Encoding UTF8
```

**Question 4**  
**Prompt**: Explain the process of photosynthesis in simple terms.  
**Answer**:  
Photosynthesis is how plants make food.  
- Plants take in sunlight, water from the soil, and carbon dioxide from the air.  
- Inside the plant’s leaves, a green pigment called chlorophyll captures the sunlight.  
- The plant uses the sunlight’s energy to mix the water and carbon dioxide into sugars (food) and oxygen.  
- The sugars give the plant energy to grow, and the oxygen is released into the air for us to breathe.

**Question 8**  
**Prompt**: Explain how a bill becomes a law in the United States.  
**Answer**:  
1. **Drafting**: A member of Congress writes a bill.  
2. **Introduction**: The bill is introduced in either the House or the Senate.  
3. **Committee Review**: The bill goes to a committee that studies it and may hold hearings.  
4. **Markup**: The committee can change the bill.  
5. **Floor Debate**: The bill is debated and voted on by the full chamber.  
6. **Other Chamber**: The bill goes to the other chamber for a similar process.  
7. **Conference Committee**: If both chambers pass different versions, a committee resolves differences.  
8. **Final Vote**: Both chambers vote on the final version.  
9. **Presidential Action**: The President signs the bill into law or vetoes it.  
10. **Override**: If vetoed, Congress can override with a two‑thirds vote.
