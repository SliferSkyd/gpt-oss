## Exercise 3: Using @PathVariable

Question: Write a Spring Boot REST controller with a GET endpoint "/square/{number}" that takes a path variable "number" and returns the square of that number as a string.

Answer:

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class MathController {
    
    @GetMapping("/square/{number}")
    public String square(@PathVariable int number) {
        int square = number * number;
        return String.valueOf(square);
    }
}
```

```python
import codecs
```

### 4. 在Java中使用 `InputStreamReader` 和 `OutputStreamWriter`

如果你在Java中处理文件，可以使用 `InputStreamReader` 和 `OutputStreamWriter` 来处理不同编码的文件：

```java
import java.io.*;

public class EncodingExample {
    public static void main(String[] args) throws IOException {
        // 读取GBK编码的文件
        try (BufferedReader reader = new BufferedReader(new InputStreamReader(new FileInputStream("input.txt"), "GBK"))) {
            String line;
            try (BufferedWriter writer = new BufferedWriter(new OutputStreamWriter(new FileOutputStream("output.txt"), "UTF-8"))) {
                while ((line = reader.readLine()) != null) {
                    writer.write(line);
                    writer.newLine();
                }
            }
        }
    }
}
```

**Question 4**  
**Prompt**: Explain the process of photosynthesis in simple terms.  
**Answer**:  
Photosynthesis is how plants make food.  
- Plants take in sunlight, water from the soil, and carbon dioxide from the air.  
- Inside the plant’s leaves, a green pigment called chlorophyll captures the sunlight.  
- The plant uses the sunlight’s energy to mix the water and carbon dioxide into sugars (food) and oxygen.  
- The sugars give the plant energy to grow, and the oxygen is released into the air for us to breathe.

**Question 8**  
**Prompt**: Explain how a bill becomes a law in the United States.  
**Answer**:  
1. **Drafting**: A member of Congress writes a bill.  
2. **Introduction**: The bill is introduced in either the House or the Senate.  
3. **Committee Review**: The bill goes to a committee that studies it and may hold hearings.  
4. **Markup**: The committee can change the bill and then votes to send it to the full chamber.  
5. **Debate**: The full House or Senate debates the bill and may propose amendments.  
6. **Vote**: The chamber votes on the bill. If it passes, it goes to the other chamber, where the process repeats.  
7. **Conference Committee**: If the two chambers pass different versions, a conference committee reconciles them.  
8. **Final Vote**: Both chambers vote on the final version.  
9. **Presidential Action**: The President signs the bill into law or vetoes it.
